# MeusExames

Meus exames, é um aplicativo no qual permite você manter o histórico de seus exames guardando fotos 
e documentos correspondente aos resultados.

**Backup:** o backup automático do Android no Google Drive guarda no máximo 25 MB por app. Acima 
disso o Android deixa de fazer o backup do MeusExames. Ao trocar de celular, guarde antes os 
arquivos dos seus exames (botão Compartilhar).

Clone o repositório pelo Android Studio:
```text
git@github.com:drmcarvalho/MeusExames.git
```

Ou pelo git linha de comando:
```shell
git clone git@github.com:drmcarvalho/MeusExames.git
```

Em seguida, no Android Studio faça da aplicação build e execute.
